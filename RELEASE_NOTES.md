## Что исправлено

- **Шаги сцены не запускались** — ошибка «The specified executable is not a valid application for this OS platform» в `scripts\common.ps1`. Причина: в PowerShell имена переменных не различают регистр, и внутренняя переменная скрипта сцены (`$py` — путь к `scene.py`) затирала `$Py` — путь к Python из `common.ps1`. Кит пытался запустить `scene.py` как программу. Переменная переименована, шаги сцены запускаются.

## Установка

В программе откройте пульт клавишей `G` и нажмите «Обновить программу» — или запустите `UPDATE.bat` в папке кита. Обновление заменит `scripts\scene.ps1`.
