Первая версия Otbor: программа для ручного отбора картинок, сделанных набором FluxKit.

## Что умеет

- Показывает варианты каждого задания и раскладывает файлы в `results\_Нужные` и `results\_Ненужные`. Программа ничего не удаляет, любое решение можно отменить кнопкой «Назад».
- Ведёт очередь по разделам: персонажи, локации, мини-игры, интерфейс и сюжетный реквизит. Панель слева показывает, сколько разобрано, и переходит к нужному разделу.
- Показывает, куда картинка идёт в игре: уровень, сцену и список поиска.
- Сама отправляет в `status/status.json` этого репозитория, что готово и что надо переделать. Картинки туда не попадают.

## Установка

Нужен Windows с .NET Framework 4.5 или новее: в Windows 10 и 11 он уже есть.

- **Только программа:** скачайте `Otbor.exe` и положите в папку `results` или в корень FluxKit.
- **Программа и скрипты генерации:** скачайте `UPDATE.bat` в папку FluxKit, рядом с `jobs.json`, и запустите. Он ставит самую свежую версию из ветки `main`, а не эту конкретную.

Файл не подписан, поэтому при скачивании через браузер Windows может показать предупреждение.

При первом запуске программа попросит ключ GitHub с правом записи в этот репозиторий. Без ключа отбор работает, результат остаётся на компьютере.

## Что пока не проверено

- Успешная отправка настоящим ключом: она проверена только на имитации сервера GitHub. При сбое кнопка GitHub покажет причину, а разбор останется на компьютере.
- Работа на компьютере с настоящими результатами генерации и физической мышью: клики проверялись программно.

Инструкция, клавиши и формат файлов описаны в [README](https://github.com/levkastergit/otbor#readme).
